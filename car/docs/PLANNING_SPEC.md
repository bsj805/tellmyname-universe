     - 1단계 올라가면 허구(`홀수`), 거기서 1단계 올라가면 실제(`짝수`)가 정확히 교차 등장한다.

     2. **`estimatedPrice` (추산되는 차량 가격·유지비는 얼마인지)**: 예) `추산 가치 -45만 원 (폐기물 스티커 비용 본인 부담)`, `추산 가치 막대사탕 3개 + 요구르트 1줄`, `추산 가치 120억 갈레온 (마법부 특별 면세)`, `추산 가치 850조 원 + 반물질 연료 카트리지` (하위 호환 필드 `estimatedSalary` 동일 매핑)
     3. **`specialFeature` (탈것의 특별한 기능이나 주행 성능은 뭔지)**: AI가 사진 컨셉에 맞춰 황당하고 웃기게 지어낸 특별 기능/옵션/주행 스펙 (2~3문장, 하위 호환 필드 `specialDuty` 동일 매핑)
     4. **`aiVerdict` (AI 수석 정비사·시승 감정사의 한 줄 총평)**: 유쾌하고 뼈 때리는 도파민 시승 코멘트

## 3. 패밀리 공통 모듈 아키텍처 (`src/lib/common/*`)

`myhome`, `occupation`, `food`, `car` 등 `tellmyname.app` 패밀리 프로젝트들이 일관된 해시 알고리즘, 패밀리 네비게이션, 시드 PRNG를 공유하도록 `src/lib/common/` 디렉토리에 표준화된 공통 모듈을 구축한다.

1. **`src/lib/common/hash_engine.js`**:
   - `CHOSUNG`, `JUNGSUNG`, `JONGSUNG`, `STROKES`, `decomposeHangul`, `fmix32`, `getNameStrokeInfo`
   - `createDeterministicHashMapper({ totalLevels, activeSlotsPerTier })`: 프로젝트별 단계 수(`1001` 또는 `20001`)에 맞춰 결정론적 해시 매퍼를 생성하는 범용 팩토리 함수.
2. **`src/lib/common/family_sites.js`**:
   - `FAMILY_SITES` 레지스트리:
     - `car`: `🚗 나에게 어울리는 자동차` (`https://car.tellmyname.app`)
     - `job`: `💼 나에게 어울리는 직업` (`https://job.tellmyname.app`)
     - `myhome`: `🏠 나에게 어울리는 집` (`https://myhome.tellmyname.app`)
     - `food`: `🍔 나에게 어울리는 음식` (`https://food.tellmyname.app`)
     - `photodiary`: `📸 포토다이어리` (`https://photodiary.tellmyname.app`)
   - 패밀리 사이트맵 URL 목록(`getFamilySitemapUrls`) 및 JSON-LD `isPartOf` / `sameAs` 생성 헬퍼.
3. **`src/lib/common/prng.js`**:
   - `mulberry32(seed)`, `normalizeSeed(rawSeed)`, `seededShuffle(array, seed)` — 이상형 월드컵 동일 대진표 URL 공유용 결정론적 난수 엔진.

## 4. 모바일 퍼스트 UI/UX 및 화면 구성 설계 (요구사항 2, 4, 5)

모바일 웹(`390×844` 등 스마트폰 세로 화면)에 완벽히 최적화하여 가로 스크롤(Horizontal Overflow)이 절대 발생하지 않도록 설계한다.

### 4.1 상단 패밀리 사이트 바 & 글로벌 3대 모드 탭
- **상단 패밀리 바**: `🚗 나에게 어울리는 자동차 (Active)` · `💼 나에게 어울리는 직업` · `🏠 나에게 어울리는 집` · `🍔 나에게 어울리는 음식` · `📸 포토다이어리` + 14개국어 전환 드롭다운 (`ko, en, ja, zh, es, fr, de, pt, ru, it, vi, id, ms, hi`)
- **브랜드 타이틀**: `🚗 나에게 어울리는 자동차 MyCar`
- **3대 모드 전환 탭**:
  1. `🚗 내 자동차 찾기` (`/`, `/name/{이름}`, `/level/{단계}`)
  2. `💀 최악 중 최선 월드컵` (`/worldcup/worst-to-best` — `0~499단계` 최악의 탈것 중 그나마 타고 다닐 최선 뽑기)
  3. `🌟 최선 중 최악 월드컵` (`/worldcup/best-to-worst` — `500~1,000단계` 대박 드림카/초월 탈것 중 의외로 제일 타기 싫은 최악 뽑기)

### 4.2 화면 1: `내 자동차 찾기` (검색바 + 랜덤 탐색 + 자동차·탈것 시승 감정서 카드 + 9:16 스토리 공유)
1. **검색바 & 랜덤 탐색**:
   - 이름 입력창 (`이름을 입력하세요 예: 김서윤, 해리포터, 홍길동...`)
   - `🎲` 주사위 버튼: 클릭 시 `name_teller` 시드 이름에서 무작위 이름을 뽑아 즉시 `/name/{이름}`으로 이동 및 시승 감정 결과 표시
   - `🔍` 검색 버튼 + 원클릭 추천 이름 칩 & `🔄` 새로고침 버튼
2. **다중우주 자동차·탈것 시승 감정평가서 메인 카드**:
   - **상단 배지**: `Tier XX` · `💀 폭망 탈것 / 🌟 대박 탈것` · `🏛️ 실존·생물 50% / 🦄 허구·마법·SF 50%` · `Lv.0 ~ Lv.1000`
   - **탈것 타이틀**: `{이름}님에게 어울리는 자동차: [탈것명]` + 카테고리 아이콘/라벨
   - **탈것 아트워크 이미지 (`1:1` 반응형 프레임)**: `/r2/cars/{00000..01000}.webp` (미생성 시 고품질 SVG 일러스트 즉시 표시)
   - **3대 핵심 스펙 그리드 (모바일 가독성 최적화 카드)**:
     - 📅 **언제 타던 탈것인지 / 연식·시대 (`era`)**
     - 💰 **추산 가격·유지비 (`estimatedPrice`)**
     - ⚡ **탈것의 특별한 기능·주행성능 (`specialFeature`)**
     - 🤖 **AI 수석 정비사 한 줄 시승 총평 (`aiVerdict`)**
   - **이름 획수 분석 아코디언 (`name_teller` 연동)**: 초·중·종성 자모 획수 및 인접 획수 조화 단계 표시
   - **인스타그램 스토리(9:16 캔버스) & 카카오톡 공유 바**:
     - `"{이름}님에게 어울리는 자동차는"` -> `'사진'` -> `'사진에 대한 설명들(연식/시대, 추산 가격, 특별 기능, AI 총평)'`이 14개 국어로 렌더링되는 9:16 캔버스 이미지 저장/전송 기능
3. **단계별 탐색 독(Dock)**:
   - `◀ 이전 단계 탈것 (Lv.X-1)` / `🎲 랜덤 탈것` / `다음 단계 탈것 (Lv.X+1) ▶`

### 4.3 화면 2: `자동차·탈것 이상형 월드컵` (모바일 상하 스크롤 선택 UX & 동일 조건 URL 공유)
- **강수 선택**: `16강` / `32강 (추천)` / `64강` / `128강` / `256강`
- **모바일 상하(Vertical Stack) 배치**: 모바일 화면(`max-width: 768px`)에서 **후보 A 탈것(위)** — **`VS` 배지(중앙)** — **후보 B 탈것(아래)**를 위아래로 스크롤하며 이미지, 탈것명, 추산 가격, 특별한 주행 기능을 비교하고 터치해 선택.
- **동일 대진표 URL 공유**: `https://car.tellmyname.app/worldcup/{mode}?round={round}&seed={seed}` 공유 및 재도전 지원.
