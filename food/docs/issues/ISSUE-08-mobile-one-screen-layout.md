# ISSUE-08: 모바일 원스크린 레이아웃 (390×844)

상위 기획: [PLANNING_SPEC_V2 §3.1](../PLANNING_SPEC_V2_MOBILE_I18N_SEO.md#31-8-모바일-원스크린-390844-기준)

## 문제
- 첫 화면에 추천 음식이 보이지 않음 (헤더+입력+시뮬레이터만 노출)
- `scrollWidth 435 > 390` 가로 스크롤 발생 ("추천받기" 버튼 잘림)
- 타임존 라벨이 1글자씩 세로로 줄바꿈
- 페이지 4,604px, 시뮬레이터가 상단 점유

## 구현 범위
- 헤더 1줄(56px)화, 부제 모바일에서 숨김, 우측에 언어 선택 슬롯(`#langSlot`, #10에서 채움) 확보
- 입력창 + 버튼 한 줄, `min-width:0` 처리로 100% 폭 안에 수납
- 추천 이름 칩: 가로 스크롤 1줄
- HERO(현재 끼니) 카드를 입력 바로 아래로 이동: 끼니 라벨/시간, 1:1 이미지(최대 240px, `aspect-ratio`), 출처 배지, 이름·한줄평 2줄 clamp, 공유 버튼 3개
- HERO 아래 5끼 미니 칩 탭(아이콘+라벨) → 탭 시 HERO 내용 교체 (해당 끼니 표시)
- 카운트다운 한 줄
- 그 아래 기존 5끼 타임라인(아침→점심→간식→저녁→야식) 유지
- 시뮬레이터 전체를 최하단 `<details>`로 이동, 기본 닫힘

## 수용 기준
- [ ] 390×844 / 375×667 / 360×740 가로 스크롤 0
- [ ] 390×844 HERO 공유 버튼 bottom ≤ 844
- [ ] 시뮬레이터 기능(타임존/시간 슬라이더/샘플 시간) 회귀 없음
- [ ] 데스크톱 ≥900px 레이아웃 정상
- [ ] `node --check web/js/app.js`, `node tests/test_all_features.mjs` 통과

## 소유 파일
`web/css/style.css`, `web/index.html`, `web/js/app.js` (단, 문자열 i18n화는 #10 범위)
