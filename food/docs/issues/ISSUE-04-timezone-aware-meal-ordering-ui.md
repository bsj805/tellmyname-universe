# [Issue #4] 접속 국가 Timezone 기반 현재 추천 끼니 최상단 노출 + 하단 스크롤 5끼 정배열(아침→점심→간식→저녁→야식) 프론트엔드 UI/UX

## 1. 개요 및 목적
- 접속한 사용자의 시간대(Timezone)와 현지 시각을 계산하여, **지금 시간에 먹어야 할 추천 끼니가 페이지 최상단(Hero 영역)에 가장 먼저 보이게** 한다.
- 그리고 **아래로 스크롤하면 시간대와 무관하게 항상 `아침 - 점심 - 간식(디저트) - 저녁 - 야식` 순서대로** 하루 전체 추천 코스가 보이도록 구성한다.
  - 예시: 오전 11시에 접속하면 **상단 Hero에는 '점심 추천'**이 크게 뜨고, **아래로 스크롤하면 `아침 → 점심(현재 시간 배지 표시) → 간식 → 저녁 → 야식` 순서대로** 카드를 확인할 수 있다.

## 2. 핵심 요구사항
1. **타임존 자동 감지 및 시간대별 끼니 매핑 (`src/lib/timezone.js`)**
   - `Intl.DateTimeFormat().resolvedOptions().timeZone`을 통해 접속자의 국가/도시 타임존(예: `Asia/Seoul`, `America/New_York`, `Europe/London`, `Asia/Tokyo`) 및 현지 날짜(`YYYY-MM-DD`), 현지 시각(`0 ~ 23시`)을 구한다.
   - 시간대별 현재 추천 끼니 규칙:
     - `05:00 ~ 09:59` → `breakfast` (**🌅 아침 추천**)
     - `10:00 ~ 13:59` → `lunch` (**☀️ 점심 추천**) *(예: 11시 접속 시 점심 추천이 최상단 노출)*
     - `14:00 ~ 16:59` → `snack` (**🍰 간식·디저트 추천**)
     - `17:00 ~ 20:59` → `dinner` (**🌙 저녁 추천**)
     - `21:00 ~ 04:59` → `night` (**🦉 야식 추천**)
   - 사용자가 다른 국가 시간대나 다른 시간(예: 08시, 11시, 15시, 19시, 23시)을 시뮬레이션해볼 수 있는 타임존/시간 프리뷰 바도 함께 제공한다.
2. **2단 레이아웃 구조 (`web/index.html`, `web/js/app.js`, `web/css/style.css`)**
   - **상단(Top Spotlight Hero)**:
     - `"🕒 현재 접속 시간대(Asia/Seoul · 11:20) 기준 — 김서윤님의 지금 추천 끼니: [☀️ 점심]"`
     - 해당 끼니의 음식 일러스트 이미지, 출처 배지(`🍱 추억의 급식`, `⭐⭐⭐ 미슐랭 3스타`, `🥕 생야채·자연식`, `🧪 이색 특이메뉴` 등), 칼로리/예상 가격, 위트 있는 추천 사유, 같이 먹으면 좋은 꿀조합 팁 표시.
   - **하단 스크롤 영역(Daily 5-Meal Full Course Timeline)**:
     - 고정 순서: **`1. 🌅 아침` → `2. ☀️ 점심` → `3. 🍰 간식(디저트)` → `4. 🌙 저녁` → `5. 🦉 야식`**
     - 현재 시각에 해당하는 끼니 카드에는 `🔥 지금 먹을 시간 (NOW)` 하이라이트 배지 부여
     - 각 카드마다 `[공유 선택 체크박스]`가 있어 원하는 음식만 골라서 공유하거나 전체를 공유할 수 있도록 연동.
