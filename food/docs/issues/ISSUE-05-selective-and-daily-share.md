# [Issue #5] 인스타그램 스토리(9:16 캔버스) & 카카오톡 공유 — '원하는 음식만 선택 공유' 및 '오늘의 추천메뉴(하루치 5끼) 전체 공유' 구현

## 1. 개요 및 목적
- 사람들이 매일 접속하여 추천받은 메뉴를 인스타그램 스토리나 카카오톡 등으로 공유할 때:
  1. **원하는 음식(끼니)만 선택해서 공유하는 모드** (예: 오늘 점심 메뉴만 단독 공유, 또는 점심+간식 2개만 선택 공유)
  2. **오늘의 추천메뉴 (하루치 5끼 전체: 아침·점심·간식·저녁·야식)를 한 번에 공유하는 모드**
- 위 두 가지 모드를 자유롭게 전환하며 9:16 고해상도 스토리 이미지(1080×1920) 생성·다운로드 및 카카오톡/링크 공유를 수행할 수 있도록 구현한다.

## 2. 핵심 요구사항
1. **공유 범위 선택 컨트롤러 (`web/js/share.js`, `web/css/share.css`)**
   - **`[📋 오늘의 추천메뉴 (하루치 5끼 전체) 공유]`** 버튼 (원클릭 전체 선택)
   - **`[✅ 원하는 음식만 선택 공유]`** 칩/체크박스 토글 (`🌅 아침`, `☀️ 점심`, `🍰 간식`, `🌙 저녁`, `🦉 야식` 중 1개~5개 자유 선택)
   - 기본값: 현재 시간대의 추천 끼니 단독 선택 또는 하루치 전체 선택 전환 탭 제공
2. **인스타그램 스토리 9:16 고해상도 캔버스(`1080 × 1920`) 듀얼 레이아웃**
   - **단일 끼니 선택 시 (Single Focus Card)**:
     - 상단: `{날짜} {이름}님의 {끼니} 추천 메뉴`
     - 중앙: 대형 일러스트 음식 아트워크 (`720 × 720`) + 출처 배지(`미슐랭 3스타` / `추억의 급식` / `생당근 자연식` 등)
     - 하단: 음식 이름, 칼로리/예상 가격, 위트 있는 추천 멘트, `food.tellmyname.app/name/{이름}` 워터마크
   - **복수 끼니 또는 하루치(5끼 전체) 선택 시 (Daily Menu Board Card)**:
     - 상단: `📅 {YYYY.MM.DD} {이름}님의 오늘 하루 추천 식단표`
     - 중앙: 선택한 끼니들(최대 5끼: 아침·점심·간식·저녁·야식)의 일러스트 썸네일 + 메뉴명 + 출처 배지 + 핵심 한 줄 요약이 고급 식단표/코스 메뉴판 형태로 정갈하게 렌더링
     - 하단: `"내 이름의 오늘 메뉴는? 👉 food.tellmyname.app"`
3. **카카오톡 공유 및 고정 링크 복사**
   - 선택된 끼니 파라미터(`?date=YYYY-MM-DD&meals=lunch,snack` 또는 `?date=YYYY-MM-DD&mode=full`)가 포함된 공유 URL 생성
   - 카카오톡 인앱 공유(Kakao SDK 또는 Web Share API / 클립보드 리치 텍스트 복사 폴백) 완벽 지원
