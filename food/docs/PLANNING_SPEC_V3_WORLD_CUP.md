# 기획서 V3: 음식 이상형 월드컵 (최고의 음식 vs 최악의 음식) & 카테고리별 SEO

## 1. 개요 및 목적
- **서비스명**: 음식 이상형 월드컵 (Food Ideal Type World Cup) — `오늘 뭐 먹지? (Mukbang)` 신규 메인 탭
- **핵심 목표**:
  1. **최고의 음식 뽑기 (Best Mode)**: 아침·점심·간식·저녁·야식·전체 카테고리 중 지금 가장 먹고 싶은 1위 음식을 토너먼트로 결정
  2. **최악의 음식 뽑기 (Worst Mode)**: 각 카테고리 중 가장 먹기 싫은 / 피하고 싶은 최악의 음식을 토너먼트로 결정
  3. **강수 자유 선택**: `32강`, `64강`, `128강` 중 사용자가 원하는 토너먼트 규모를 직접 선택 (모든 카테고리가 141~401종을 보유하여 중복 없이 128강까지 완벽 지원)
  4. **매번 랜덤 대진**: 게임 시작 시마다 카테고리 풀에서 무작위 셔플(Fisher-Yates)로 참가 음식과 대진을 매번 새롭게 구성
  5. **모바일 세로 스크롤 최적화**: 모바일 화면에서 두 후보를 **위·아래 세로 스택**으로 배치하고 **자유롭게 위아래로 스크롤**하며 이미지와 설명을 비교한 뒤 편하게 선택할 수 있도록 설계
  6. **카테고리별 검색엔진 최적화 (SEO)**: "오늘의 점심 고르기 이상형 월드컵", "오늘의 저녁 고르기 이상형 월드컵", "최악의 음식 뽑기 이상형 월드컵" 등 전용 랜딩 URL(`/worldcup/lunch`, `/worldcup/dinner`, `/worldcup/worst` 등) 및 14개국 다국어 Edge SSR · Sitemap 연동

## 3. 화면 구성 (Screen-by-Screen Design)

### 3.0 상단 메인 탭 네비게이션
기존 `[🍽 오늘의 식단]` / `[🖼 일러스트 도감]` 옆에 **`[🏆 음식 월드컵]`** 탭 추가.
- 클릭 시 SPA 라우팅(`history.pushState`)으로 `/worldcup` (또는 선택된 카테고리 `/worldcup/lunch` 등)으로 전환.

### 3.1 화면 1: 월드컵 설정 화면 (Setup Screen)
사용자가 게임 조건을 직관적으로 고르는 시작 화면.
1. **모드 선택 (2종 대형 토글 카드)**:
   - `🏆 최고의 음식 뽑기` (따뜻한 오렌지/골드 테마): 오늘 가장 먹고 싶은 최애 메뉴 찾기
   - `💀 최악의 음식 뽑기` (다크 퍼플/크림슨 테마): 절대 먹기 싫은 최악의 워스트 메뉴 찾기
2. **카테고리 선택 (6종 칩/카드 그리드)**:
   - `✨ 전체 (401)`, `🌅 아침 (163)`, `☀️ 점심 (279)`, `🍰 간식 (141)`, `🌙 저녁 (278)`, `🦉 야식 (206)`
3. **토너먼트 강수 선택 (3종 세그먼트 버튼)**:
   - `32강 (31경기)` / `64강 (63경기)` / `128강 (127경기)`
4. **시작 CTA 버튼**:
   - `[🏆 {카테고리} {강수}강 시작하기]` (모드에 따라 문구·색상 동적 변경)
5. **인기 월드컵 바로가기 (SEO & UX 퀵 링크)**:
   - `☀️ 오늘의 점심 고르기`, `🌙 오늘의 저녁 고르기`, `🦉 야식 이상형 월드컵`, `💀 최악의 음식 뽑기`

### 3.2 화면 2: 대결 화면 (Match Arena Screen)
두 후보 중 하나를 선택하는 핵심 플레이 화면.
1. **상단 상태 바**:
   - 모드 배지 (`🏆 최고` 또는 `💀 최악`)
   - 현재 라운드 & 경기 번호 (예: `점심 · 32강 1/16경기` → `16강` → `8강` → `4강(준결승)` → `결승`)
   - 진행률 프로그레스 바 (전체 경기 대비 진행 %)
   - 유틸 버튼: `[↩️ 이전]` (방금 선택 되돌리기), `[⚙️ 다시 설정]`
2. **대결 카드 레이아웃**:
   - **데스크톱 (`> 768px`)**: 좌·우 2열 그리드 + 중앙 `VS` 배지
   - **모바일 (`<= 768px`)**:
     - **위·아래 세로 스택 (`flex-direction: column`)**
     - 페이지 전체가 자연스럽게 **위아래로 스크롤 가능**하여, 위쪽 후보 카드(이미지+설명)를 본 뒤 아래로 스크롤해 아래쪽 후보 카드를 확인하고 원하는 카드를 터치로 선택
     - 중앙에 `VS` 구분 배지 배치
     - 선택 시 짧은 하이라이트 피드백 후 다음 대결로 전환되며, 아레나 상단으로 부드럽게 스크롤 이동
3. **후보 카드 구성 요소**:
   - 고해상도 1:1 음식 일러스트 (`images/web/{code}.webp` + SVG 폴백)
   - 원산지/유형 배지 (예: `⭐ 미슐랭`, `🍱 급식`, `🍲 한국인기`)
   - 음식 이름 (다국어 지원)
   - 한줄 설명 (`tagline`) 및 칼로리/가격 스펙
   - 하단 명확한 선택 버튼 (`👍 이게 더 좋아요!` / `👎 이게 더 최악이에요!`)

### 3.3 화면 3: 최종 우승 결과 화면 (Winner Result Screen)
결승전 종료 후 우승 음식을 축하/발표하는 화면.
1. **우승 배너**:
   - Best 모드: `🏆 최종 우승! 오늘의 최고 {카테고리}`
   - Worst 모드: `💀 최종 우승! 최악의 {카테고리}`
2. **우승 음식 쇼케이스 카드**:
   - 대형 일러스트, 우승 배지, 음식명, 상세 설명, 칼로리/가격, 토너먼트 요약 (`{강수}강 토너먼트 우승`)
3. **액션 & 공유 버튼**:
   - `[📸 인스타 스토리로 보내기]` / `[⬇️ 이미지 저장]` / `[💬 카카오톡 공유]` / `[🔗 결과 링크 복사]`
   - `[🔍 음식 상세 정보 보기]` (도감 상세 모달 연결)
   - `[🔄 같은 조건으로 랜덤 재도전]`
   - `[🎯 다른 카테고리·모드 고르기]`

## 4. 토너먼트 엔진 알고리즘 (`src/lib/worldcup.js`)
1. `filterFoodsByCategory(foods, category)`: `all` 또는 `candidateMeals`/`primaryMeal` 기준 필터링
2. `shuffleArray(array, rng)`: Fisher-Yates 무작위 셔플 (매 게임 새 대진)
3. `createWorldCupBracket({ foods, category, mode, roundSize, rng })`:
   - 셔플 후 `roundSize`개 추출
   - 초기 라운드 매치 페어 생성 (`[[a, b], [c, d], ...]`)
4. `pickMatchWinner(state, side)` (`'left' | 'right'`):
   - 승자를 `nextRoundPool`에 추가, 히스토리 스택에 스냅샷 저장(Undo 지원)
   - 현재 라운드 모든 매치 완료 시:
     - `nextRoundPool.length === 1` → `phase = 'finished'`, `winner = nextRoundPool[0]`
     - 그 외 → `nextRoundPool`을 다시 셔플하여 다음 라운드(`roundSize / 2`) 매치 생성
5. `undoLastPick(state)`: 직전 선택 상태로 복원

## 5. SEO 전략 (`/worldcup` & 전용 랜딩 페이지)
1. **전용 SEO 라우트 (Cloudflare Worker Edge SSR)**:
   - `/worldcup` — 음식 이상형 월드컵 | 오늘 뭐 먹지?
   - `/worldcup/breakfast` — 오늘의 아침 고르기 이상형 월드컵
   - `/worldcup/lunch` — 오늘의 점심 고르기 이상형 월드컵
   - `/worldcup/snack` — 오늘의 간식 고르기 이상형 월드컵
   - `/worldcup/dinner` — 오늘의 저녁 고르기 이상형 월드컵
   - `/worldcup/night` — 오늘의 야식 고르기 이상형 월드컵
   - `/worldcup/worst` — 최악의 음식 뽑기 이상형 월드컵
2. **다국어 & 검색엔진 메타 최적화**:
   - 14개 언어(`?lang=xx` 및 `/{lang}/worldcup...`) 지원
   - Naver Search Advisor 기준 `<title>` 40자 내외 핵심 키워드 전면 배치, `<meta name="description">` 80자 내외 자연스러운 한국어 문구
   - Self-referencing `<link rel="canonical">`, 15개 `<link rel="alternate" hreflang="...">`, OpenGraph, Twitter Card, JSON-LD (`WebApplication` + `BreadcrumbList`)
   - Non-JS 크롤러(Naver Yeti, Googlebot, Baiduspider, YandexBot)를 위한 Static SSR 본문 폴백 삽입
   - `/sitemap-pages.xml`에 모든 월드컵 랜딩 URL × 14개 언어 자동 등록
