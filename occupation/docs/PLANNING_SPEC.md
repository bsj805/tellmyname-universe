## 0. 핵심 컨셉 및 기획 목표 요약

1. **이름 해시 기반 `0 ~ 1,000` 단계 (총 1,001종) 결정론적 매핑 (요구사항 0)**
   - `name_teller`의 한글 초·중·종성 자모 분해 및 획수 합산 철학(`STROKES`, 인접 글자 획수 조화값 `mod 10`)을 계승한 **`JSA-Hash-1001` (Jamo-Stroke Avalanche Hybrid Hash)** 엔진을 사용한다.
   - 이름을 입력하면 언제 어디서나 항상 똑같은 `0 ~ 1,000` 사이의 숫자로 매핑되어 해당 단계의 직업 이미지와 감정서를 보여준다.
   - `name_teller`의 50,000개 시드 이름을 전수 테스트하여 `0 ~ 1,000` 전 구간(1,001개 슬롯) 100% 점유 및 폭망(`0~499`) : 대박(`500~1,000`), 짝수(실제) : 홀수(허구) 50:50 균등 분포를 검증한다.

2. **평범함 제로(Zero Normalcy) · 극단적 폭망/대박 스펙트럼 & 50:50 실제/허구 1단계 교차 (요구사항 1, 1.1, 1.3, 1.4)**
   - **평범한 회사원, 일반 공무원 등은 절대 그대로 나오지 않는다.** 평범한 직업 명칭이더라도 **"대설특보 속에서 눈사람이 된 채 인터뷰하는 박대기 기자"**, **"비트코인 8조 원을 훔쳐 화성 도피 중인 천재 해커"**처럼 극단적이고 허무맹랑하거나 황당하고 웃긴 일을 하고 있어야 한다.
   - **`0단계 ~ 499단계 (총 500종)` — 극단적으로 안 좋은 직업 (💀 폭망 잡 / 극한 알바)**
     - `0단계`가 우주에서 제일 안 좋은 직업이며 연봉이 가장 낮다(적자/벌금/수명 단축).
     - 역사 속 극한 직업(런던 하수구 오물 채집꾼, 중세 왕실 변기 닦이), 골방백수·방구석 폐인, 블랙기업 노예, 판타지/SF 최하층 잡졸(데스스타 배기구 걸레질 당번, 사우론 용암 반지 광택 알바) 등.
   - **`500단계 ~ 1,000단계 (총 501종)` — 극단적으로 좋은 직업 (🌟 대박 잡 / 신의 직장 / 초미래 직업)**
     - `500단계`부터 좋은 직업이 시작되며, `1,000단계`는 초미래 다중우주에서 가장 가치가 높고 연봉이 천문학적인 직업이다.
     - 세계의 황당한 꿀직업(트로피컬 아일랜드 산호초 수면 감별사, 팬더 안아주기 테라피스트, 8조 원 해커), 범지구 메가프로젝트 총괄, 은하계 테라포밍 감독관, 블랙홀 에너지 채굴 재벌, 다중우주 시공간 아키텍트(`Lv.1000`).
   - **짝수(실제/역사 실존) 50% ↔ 홀수(허구/상상/SF·판타지) 50% 1단계 교차 법칙**
     - **`짝수 단계 (level % 2 === 0, 501종)`**: 실제 존재하거나 역사상 존재했던 황당·극한·초고소득 직업/일거리/장사거리/관광거리.
     - **`홀수 단계 (level % 2 === 1, 500종)`**: 허구·상상 속의 직업, 공상과학(SF)·판타지 영화/소설/애니메이션 속 일자리, 초미래 직업.
     - 1단계 올라가면 허구(`홀수`), 거기서 1단계 올라가면 실제(`짝수`)가 정확히 교차 등장한다.

3. **직업 감정서 3대 필수 스펙 + AI 총평 (요구사항 1.0)**
   - 사진을 보여줄 때 아래 3가지 핵심 항목과 AI 총평을 황당하고 웃기게 제시한다:
     1. **`era` (언제 하던 직업인지)**: 예) `기원전 2,500년 고대 이집트 피라미드 야간 당번`, `2010년 1월 4일 폭설 내리던 저녁 8시`, `서기 45,000년 안드로메다 은하 제3제국`
     2. **`estimatedSalary` (추산되는 연봉은 얼마인지)**: 예) `연봉 -850만 원 (눈삽 파손 변상금 포함)`, `연봉 보리쌀 3가마니 + 건빵 2봉지`, `연봉 8조 4,000억 원 (비트코인 비과세)`, `연봉 은하계 행성 12개 + 반물질 500톤`
     3. **`specialDuty` (직업의 특별한 역할이나 할일이 뭔지)**: AI가 사진 컨셉에 맞춰 황당하고 웃기게 지어낸 특별 직무/할일 (2~3문장)
     4. **`aiVerdict` (AI 인사팀장의 한 줄 감정 총평)**: 유쾌하고 뼈 때리는 도파민 코멘트

4. **이미지 프롬프트(`0.txt ~ 1000.txt`) 구축 및 자동 생성 + 내장 이미지 생성기 Fallback (요구사항 1.2)**
   - 실제 사진을 무단 크롤링하지 않고, `images/0.txt`부터 `images/1000.txt`(및 5자리 패딩 호환)까지 프롬프트를 생성해 둔다.
   - `Gemini_jobs_이미지자동생성.bat` (및 `C:\Users\USER\Desktop\Gemini_jobs_이미지자동생성.bat`) + `auto_generator.py`를 통해 이미지 생성을 실행하고, 실패하거나 누락된 이미지는 내장 `image-generator` 서브에이전트(`txt-to-image-generator` 스킬)로 보완 생성한다.
   - 아직 생성되지 않은 단계의 이미지도 즉시 깨짐 없이 볼 수 있도록 Cloudflare Worker 엣지에서 고품질 직업 일러스트 SVG 폴백을 실시간 렌더링한다.

5. **영구 공유 URL (`job.tellmyname.app/name/{이름}`) & 랜덤 이름 탐색 & 이상형 월드컵 (요구사항 2, 3, 4, 5)**
   - **고정 공유 URL**: `https://job.tellmyname.app/name/{이름}`으로 접속 시 항상 동일한 직업 결과 페이지를 SSR로 렌더링하여 인스타그램 스토리(9:16 캔버스), 카카오톡, 트위터/X, 링크 복사로 즉시 공유 가능.
   - **Cloudflare R2 연동**: `/r2/jobs/{00000..01000}.webp` (또는 `.png`) 동일 도메인 R2 라우터 탑재.
   - **랜덤 이름 탐색**: 주사위 버튼(`🎲`) 클릭 시 `name_teller` 시드 이름 중 랜덤 이름을 즉시 검색하고, 추천 이름 칩 새로고침 및 이전/다음/랜덤 단계 탐색 지원.
   - **직업 이상형 월드컵 (별도 탭 & 모바일 상하 스크롤 최적화)**:
     - **탭 1 (`🏠 내 직업 찾기`)**: 이름 검색 및 직업 감정서 결과 카드
     - **탭 2 (`💀 최악 중 최선 월드컵`)**: `0~499단계` 최악의 극한 직업 중에서 그나마 할 만한 최선의 직업을 뽑는 이상형 월드컵 (`/worldcup/worst-to-best`)
     - **탭 3 (`🌟 최선 중 최악 월드컵`)**: `500~1,000단계` 최고의 대박 직업 중에서 의외로 제일 하기 싫은 최악의 직업을 뽑는 이상형 월드컵 (`/worldcup/best-to-worst`)
     - **라운드 선택**: `16강 / 32강 / 64강 / 128강 / 256강` 자유 선택, 매 대진마다 중복 없이 랜덤 매칭.
     - **모바일 UX**: 모바일 화면(390×844 등)에서 두 후보 직업을 **위·아래(상하 수직 배치)**로 스크롤하며 이미지와 연봉·할일을 한눈에 비교하고 터치해 선택할 수 있도록 최적화.

## 3. 모바일 퍼스트 UI/UX 및 화면 구성 설계 (요구사항 2, 4, 5)

모바일 웹(`390×844` 등 스마트폰 세로 화면)에서 가장 많이 접속하므로 모든 화면은 **모바일 퍼스트(Mobile-First)**로 설계하고 매 구현 단계마다 검증한다.

### 3.1 상단 헤더 & 글로벌 3대 모드 탭
- **유틸리티 바**: 포토 다이어리 / 내 집 찾기(`myhome.tellmyname.app`) 패밀리 링크 + 14개국어 전환 드롭다운 (`ko, en, ja, zh, es, fr, de, pt, ru, it, vi, id, ms, hi`)
- **브랜드 타이틀**: `💼 나에게 어울리는 직업 MyJob`
- **3대 모드 전환 탭 (터치 친화적 풀와이드 필 버튼)**:
  1. `💼 내 직업 찾기` (`/`, `/name/{이름}`, `/level/{단계}`)
  2. `💀 최악 중 최선 월드컵` (`/worldcup/worst-to-best` — `0~499단계` 극한 직업 중 그나마 할 만한 최선 뽑기)
  3. `🌟 최선 중 최악 월드컵` (`/worldcup/best-to-worst` — `500~1,000단계` 대박 직업 중 의외로 제일 싫은 최악 뽑기)

### 3.2 화면 1: `내 직업 찾기` (검색바 + 랜덤 탐색 + 직업 감정서 카드 + 공유)
1. **검색바 & 랜덤 탐색**:
   - 이름 입력창 (`이름을 입력하세요 예: 김서윤, 박대기, 홍길동...`)
   - `🎲` 주사위 버튼: 클릭 시 `name_teller` 시드 이름에서 무작위 이름을 뽑아 즉시 `/name/{이름}`으로 이동 및 감정 결과 표시
   - `🔍` 검색 버튼
   - **추천 이름 칩**: `김서윤 (Lv.XXX)`, `이민준`, `홍길동`, `박대기`, `사토시` 등 원클릭 테스트 칩 + `🔄` 새로고침 버튼
2. **다중우주 직업 감정평가서(임명장) 메인 카드**:
   - **상단 배지**: `Tier XX` · `💀 폭망 잡 / 🌟 대박 잡` · `🏛️ 실존·역사 50% / 🦄 허구·상상 50%` · `Lv.0 ~ Lv.1000`
   - **직업 타이틀**: `{이름}님에게 어울리는 직업: [직업명]` + 카테고리 아이콘/라벨
   - **직업 아트워크 이미지 (`1:1` 또는 `16:9` 반응형 프레임)**: `/r2/jobs/{00000..01000}.webp` (미생성 시 고품질 SVG 일러스트 즉시 표시)
   - **3대 핵심 스펙 그리드 (모바일 가독성 최적화 카드)**:
     - 📅 **언제 하던 직업인지 (`era`)**

## 4. Cloudflare 정적 호스팅 (Zero-File-Explosion) + R2 + 글로벌 SEO 아키텍처

1. **파일 개수를 늘리지 않는 정적 호스팅 (`dist/` 파일 50개 미만 유지)**
   - 50,000개의 이름 페이지나 1,001개의 직업 페이지를 물리적 HTML 파일로 생성하지 않는다.
   - `worker.js`가 Cloudflare Edge에서 `/`, `/name/:name`, `/level/:level`, `/worldcup`, `/worldcup/worst-to-best`, `/worldcup/best-to-worst` 요청을 가로채어 실시간으로 `<title>`, `<meta name="description">`, OpenGraph(`og:title`, `og:description`, `og:image`, `og:url`), Schema.org JSON-LD(`JobPosting`, `Occupation`, `WebApplication`, `FAQPage`, `ImageObject`), 시맨틱 본문(`<article class="seo-job-ssr">`)을 주입하여 반환한다.
2. **Cloudflare R2 오브젝트 스토리지 연동 (`occupation-jobs-r2`)**
   - R2 버킷 내 `jobs/00000.webp` ~ `jobs/01000.webp` (및 `.png`)를 저장하고, Worker가 `/r2/jobs/:filename` 경로로 동일 도메인(Same-Origin) 서빙(`Cache-Control: public, max-age=31536000, immutable`)을 제공한다.
   - 로컬 개발 서버(`scripts/dev_server.mjs`)에서는 프로젝트 내 `images/` 폴더의 생성된 PNG/WebP를 최우선 서빙하고, 미생성 시 즉석에서 SVG 아트워크를 생성해 보여준다.
3. **검증된 초강력 SEO (`seo-optimizer` 스킬 규격 100% 준수)**
   - **네이버 서치어드바이저(`Yeti`) 최적화**: 루트 `<title>` 40자 이내 (`나에게 어울리는 직업 - 이름만 입력해서 찾는 재미로 보는 직업 테스트`), `<meta name="description">` 80자 이내, `/rss.xml` (50개 시드 이름 직업 감정 피드) 제공.
   - **이상형 월드컵 타겟 키워드 SEO**: `나의 직업 고르기 이상형 월드컵`, `나에게 어울리는 직업`, `직업 이상형 월드컵`, `최악의 직업 월드컵`, `극한직업 이상형 월드컵`, `꿀직업 월드컵`, `이름으로 보는 직업 테스트` 등 전용 메타 및 SSR 랜딩 구축.
   - **대규모 분할 사이트맵**:
     - `/sitemap.xml` (인덱스)
     - `/sitemap-main.xml` (메인, 월드컵 3종, `0~1,000` 전체 직업 레벨, 14개 언어 `xhtml:link hreflang`)
     - `/sitemap-images.xml` (`0~1,000` 직업 이미지 Google Image Sitemap)
     - `/sitemap-names-1.xml` & `/sitemap-names-2.xml` (`name_teller` 50,000개 시드 이름 URL)
