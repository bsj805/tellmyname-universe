## 🌟 핵심 기획 요약

1. **0 ~ 20,000단계 극단적 병맛 & 도파민 하우스 (`JSA-Hash-20001` 매핑)**
   - 한국어 2글자·3글자·4글자 이름을 `name_teller`의 자모 획수 테이블 + 아발란체 해시(`JSA-Hash-20001`)로 매핑하여 **50,000개 시드 이름 기준 92.04% 단계 커버리지(포아송 이론치 91.79% 상회), 폭망:대박 = 49.83% : 50.17%, 짝수:홀수 = 49.97% : 50.03%**의 완벽한 균등분포 달성.
2. **평범한 아파트 절대 금지 & 50:50 실제/허구 1단계 교차**
   - **`0 ~ 9,999단계`**: 극단적으로 안 좋은 폭망 하우스 (푸세식 화장실, 택배 종이상자, 개집, 아즈카반 독방, 구룡성채 등)
   - **`10,000 ~ 20,000단계`**: 극단적으로 좋은 대박 하우스 (핵미사일 사일로 벙커, 하울의 움직이는 성, 아이언맨 저택, 부르즈 할리파, 국제우주정거장 ISS, 다이슨 스피어 등)
   - **`짝수 단계 (0, 2, 4...)`**: 실제 존재하는 기이한 건축물·사물
   - **`홀수 단계 (1, 3, 5...)`**: 허구(상상·영화·소설·초현실)의 건축물·사물
3. **Gemini 3.8 Flash 기반 아트워크 & AI 감정평가서**
   - 모든 단계의 이미지를 **Gemini 3.8 Flash**로 생성하여 **Cloudflare R2**에 저장.
   - 사진과 함께 **① 언제 지어진 집인지**, **② 추산 가치는 얼마인지**, **③ 집의 특별한(황당한) 기능은 무엇인지** 노출.
4. **파일 개수를 늘리지 않는 Cloudflare 정적 호스팅 + 50,000개 Sitemap (네이버·구글 SEO)**
   - 물리적 HTML 파일 증식 없이 단일 SPA + Cloudflare Worker 엣지 SSR로 50,000개 이름 URL 서빙.
   - `name_teller` 시드 이름 50,000개를 분할 사이트맵(`sitemap-names-1.xml`, `sitemap-names-2.xml`)에 등록하여 네이버(`Yeti`) 및 구글 검색 노출 극대화.
5. **탐색 및 바이럴 공유**
   - `https://myhome.tellmyname.app/name/{이름}` 고정 URL로 인스타그램 스토리(9:16 캔버스)·카카오톡 공유.
   - `[◀ 이전 단계 집 보기]`, `[다음 단계 집 보기 ▶]`, `[🎲 랜덤 집 보기]` 탐색 지원.
