## 1. 택소노미 3대 절대 설계 원칙

1. **평범함 제로(Zero Normalcy) 원칙**:
   - 대한민국 흔한 30평 아파트, 일반 원룸, 평범한 단독주택은 **단 하나도 존재하지 않습니다.**
   - `0 ~ 9,999단계 (폭망 하우스)`: **"여기서 어떻게 살아?!"** 싶은 극단적 밑바닥, 유황 광산, 쓰레기통, 개집, 옷장, 폐가, 디스토피아 감옥.
   - `10,000 ~ 20,000단계 (대박 하우스)`: **"이게 집이라고?!"** 싶은 핵미사일 사일로 호화 콘도, 아이언맨 절벽 저택, 부르즈 할리파 꼭대기, 다이슨 스피어, 관측 가능한 우주 펜트하우스.

2. **50:50 짝수(실제) / 홀수(허구) 1단계 완벽 교차 법칙**:
   - **짝수 (`level % 2 === 0`, 10,001종)**: **실제 존재하는(또는 역사상 실존했던) 기상천외한 건축물·사물** (`REAL`)
     - 구룡성채, 알카트라즈, 체르노빌 관람차, 폴란드 거꾸로 된 집, 케레트 하우스, 류경호텔, 서바이벌 콘도, 구겐하임 빌바오, 노이슈반슈타인 성, 부르즈 할리파, 스발바르 종자저장고, CERN 대형 강입자 충돌기, 국제우주정거장 ISS, 라니아케아 초은하단, 관측 가능한 우주 박물관.
   - **홀수 (`level % 2 === 1`, 10,000종)**: **허구·영화·소설·애니·상상·SF·B급 초현실 공간** (`FICTION`)
     - 마그마 반지하, 쿠팡 보냉백 복층, 해리포터 계단 밑 벽장, 모우닝 머틀 화장실, 아즈카반 감옥, 설국열차 꼬리칸, 마인크래프트 용암 위 1블록, 에셔의 무한 계단, 신라면 큰사발 뗏목, 오징어게임 유리 징검다리, 바벨탑 옥탑방, 배트케이브, 하울의 움직이는 성, 아이언맨 말리부 저택, 아틀란티스 해저 왕궁, 와칸다 왕궁, 엔터프라이즈호, 데스스타, 아스가르드 궁전, 다중우주 시뮬레이션 서버실.
   - 사용자가 `[다음 집 (+1)]` 또는 `[이전 집 (-1)]`을 누를 때마다 **실제 ↔ 허구**가 1단계 단위로 번갈아 나타나 탐색 몰입도를 극대화합니다.

3. **12대 비(非)주택 괴짜 카테고리 총망라**:

## 5. Cloudflare R2 및 청크 서빙 아키텍처

- **물리 청크 파일**: `data/chunks/houses-chunk-00.json` ~ `houses-chunk-19.json` (총 20개 파일, 평균 크기 ~250KB)
- **Zero-File-Explosion 배포**: Cloudflare 20,000개 파일 개수 제한을 우회하기 위해 개별 HTML 대신 20개 청크를 정적 호스팅(`dist/data/`)에 배치하고, 클라이언트 SPA 또는 Cloudflare Edge Worker(`worker.js`)에서 온디맨드로 인덱싱합니다.
- **R2 이미지 규격**: 모든 이미지는 동일 도메인(Same-Origin) 프록시 경로 `/r2/houses/XXXXX.webp` 및 절대 URL `https://myhome.tellmyname.app/r2/houses/XXXXX.webp`로 연결됩니다.
