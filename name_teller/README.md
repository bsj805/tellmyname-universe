## 🌟 서비스 소개

**「이름을 설명해드립니다」**는 대한민국 300개 모든 성씨와 15,487개의 한글 이름, 시집·문학 작품 속 시어, 그리고 대법원 인명용 한자를 결합하여 모든 사람에게 자신의 이름에 깃든 가장 찬란하고 서정적인 뜻을 선물하는 감성 웹 서비스입니다.

이름 뜻을 확인하고, 인스타그램 스토리나 카카오톡 프로필 링크를 통해 친구들에게 전용 우체통을 공유하여 365일 동안 따뜻한 텍스트 익명 편지를 주고받을 수 있습니다.

## 🚀 핵심 기능 (Features)

### 1. 📖 15,487개 마스터 이름 데이터베이스 & 감성 뜻풀이
- **대법원 인명용 한자 풀 결합**: 음절별 상형·회의·형성 원리와 훈음을 정밀 매핑하여 시적이고 품격 있는 한자 뜻풀이 제공
- **시집·한국 문학 시어 발굴**: 교과서 및 현대 시집에서 추출한 순우리말 2~3음절 단어(조사 제거 정제) 수록
- **6가지 동음이의 한자 버전 스크롤**: 같은 한글 이름이라도 대표 표준, 서정·우아, 고전·문헌, 온화·안식, 명철·서광, 순우리말 버전 등 6가지 해석을 비교하고 대표 카드로 선택 가능

### 2. 📱 인스타그램 릴스(Reels) 스타일 세로 스냅 스크롤 피드
- **한 손 스와이프 탐색**: 위아래로 가볍게 스크롤하며 다양한 이름의 카드와 뜻풀이를 인스타그램 릴스처럼 연속 탐색
- **랜덤 추천 무한 모드**: 버튼 하나로 무작위 추천 이름 피드로 전환되어 새로운 아기 이름 작명 아이디어 탐색 가능
- **인피드 네이티브 카드**: 스크롤 피드 4번째마다 자연스럽게 어우러지는 반응형 카드 배치

### 3. 💌 365일 보관 가벼운 텍스트 채팅형 익명 편지함
- **가벼운 카카오톡/DM 말풍선 UI**: 별도의 회원가입 없이 누구나 이름 주인에게 익명으로 응원과 마음을 전달
- **텍스트 전용 청정 환경**: 사진·이미지 첨부 불가로 악성 파일 유입을 원천 차단하고 서버 부담 최소화
- **365일 롤링 보관 & 자동 파기**: 매일 일일 배치로 지난 1년간의 편지만 안전하게 서빙하고 만료된 데이터는 자동 삭제

### 4. 🇰🇷 대한민국 300개 모든 성씨 결합 & 자동 분리 라우팅
- **단성·복성 286개+ 전 성씨 지원**: 김·이·박·최·정 등 1자 성씨부터 남궁·황보·제갈·선우·독고 등 2자 복성까지 완벽 지원
- **스마트 파싱 라우팅**: `/name/김서윤`, `/name/남궁서윤` 등 어떤 성씨를 붙여 검색해도 성씨(金)와 이름(서윤)을 지능적으로 분리하여 해당 이름의 데이터로 라우팅
- **성씨 궁합 배너 & 성씨 퀵 스위처**: 1클릭으로 대한민국 주요 성씨를 갈아끼우며 어울림과 획수 조화 확인 가능

### 5. 📊 이름별 실시간 검색통계 대시보드
- 해당 이름의 누적 조회수, 상위 % 순위(S+/S/A/B 티어)
- 세대별 선호도 트렌드 및 남녀 성비 분포
- 함께 가장 많이 검색된 인기 성씨 결합 TOP 8 실시간 집계

### 6. 🔍 검색엔진 최적화 (Programmatic SEO) & 호기심 유발 티저
- **호기심 자극 6~7자 미리보기**: 검색결과에 뜻 전체가 아닌 `"하늘이 내린..."`처럼 말줄임표로 일부만 노출하여 클릭률 극대화
- **SEO 랜딩 페이지 생성**: 주요 이름별 정적 URL (`/name/[이름]/`) 및 Schema.org 구조화 데이터(JSON-LD, FAQ) 완비
- **서치콘솔 & 서치어드바이저 사이트맵**: `sitemap.xml`, `sitemap-surnames.xml`, `rss.xml`, `robots.txt` 자동 빌드

### 7. 💰 구글 애드센스 (Google AdSense) 완벽 연동
- 공식 퍼블리셔 ID(`ca-pub-8793936135959956`) 탑재
- 상단 배너, 본문 인아티클, 채팅 인피드, 릴스 스냅 인피드 등 정책 준수 광고 슬롯 구축
- 구글 심사 필수 페이지 완비: `ads.txt`, `privacy.html`(개인정보처리방침), `terms.html`(이용약관)

```text
name_teller/
├── dist/                                      # Cloudflare Pages에 배포되는 최적화된 정적 사이트 (Zero-Cost Hosting)

│   ├── privacy.html / terms.html              # 구글 애드센스 필수 법적 고지 페이지

│   └── ads.txt                                # 구글 공식 퍼블리셔 인증
├── data/
│   ├── compact_serving_names.json             # 15,487개 이름 압축 서빙 데이터
│   ├── korean_surnames_all.json               # 대한민국 300개 전 성씨(단성/복성) 데이터

│   └── messages/                              # 일자별 익명 편지 JSON (365일 롤링 보관)
├── functions/api/                             # Cloudflare Pages Functions (익명편지·검색 큐 브릿지)
├── scripts/
│   ├── generate_static_site.mjs               # dist/ 정적 사이트 빌더
│   ├── batch_daily_update.mjs                 # GitHub Issue 큐 수집 및 365일 메시지 일일 배치
│   ├── dev_server.mjs                         # 로컬 개발 서버
│   └── configure_adsense.mjs                  # 애드센스 퍼블리셔 ID 원클릭 적용 도구
├── .github/workflows/
│   └── daily_batch_deploy.yml                 # 매일 자동 배치 워크플로우
├── wrangler.toml                              # Cloudflare Pages 프로젝트 설정
└── LICENSE                                    # 상업적 이용 및 무단 복제 금지 독점 라이선스
```
