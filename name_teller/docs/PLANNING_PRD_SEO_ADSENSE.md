# 📋 [종합 기획서 v2.0] 이름을 설명해드립니다 — 한글 이름 한자 뜻풀이 & 익명 메시지 전달소

> **본 기획서는 정밀 품질 검증을 거쳐 SEO 스팸 페널티 방어, 한자 음가 무결성, Google AdSense 수익화 안정성을 완벽히 보완한 최종본(v2.0)입니다.**

## 1. 서비스 비전 및 정체성
- **서비스명**: **이름을 설명해드립니다 (Name Teller)**
  - **의미**: "세상 모든 이름의 뜻풀이와 익명 편지를 정성껏 품질 검수하여, 가장 예쁘고 따뜻한 결과물만 선물하는 감성 서비스"
- **핵심 가치 제안**:
  1. **모든 한글 이름의 가장 예쁜 한자 뜻풀이 아카이브**: 대한민국에 존재하는 모든 한글 이름에 대해 대법원 인명용 한자 중 가장 시적이고 아름다운 의미 조합을 큐레이션합니다.
  2. **Gemini 생성 에이전트 × 품질 검증 파이프라인 (Self-Growing Verified DB)**: 사전 구축된 셋(Seed DB)에 없는 이름이 검색되면, 실시간으로 생성 에이전트가 뜻풀이를 짓고 품질 검증 로직이 음가 정확성·인명용 여부·문장 독창성을 검수(90점 이상 통과)한 뒤 우리의 DB로 영구 축적합니다.
  3. **이름 기반 익명 메시지 전달소 (Anonymous Message Station)**: 같은 이름을 가진 사람들에게 도착한 공개 응원 담벼락과 개인 전용 공유 링크(`/name/서윤?to=합정동_서윤`)를 통해 SNS 바이럴과 재방문을 유도합니다.

## 2. 데이터 플라이휠 & 품질 검증 파이프라인 (Architecture)

```text
[방문자/검색봇 유입: /name/윤슬]
       │
       ▼
[1단계: 한글 이름 음운/유효성 필터] ──(비정상 문자열 '쀍뛣' 차단)──> 400 Bad Request (noindex)
       │ (유효한 한글 이름)
       ▼
[2단계: PostgreSQL / Supabase DB 조회]
  ├─ (DB에 존재함: Seed 또는 기존 생성분) ──> 0.05초 만에 SSR/ISR 캐시 응답 + 조회수 +1
  │
  └─ (DB에 없음: 신규 한글 이름!)
       │
       ▼
[3단계: Gemini Creator Agent 호출]
  - 음절별 검증된 인명용 한자 후보군 참조
  - 가장 예쁜 대표 한자 조합 + 서브 조합 2선 + 700자 스토리텔링 + SEO FAQ 3문항 생성
       │
       ▼
[4단계: Quality Verification Subagent (품질 검증 검수)]
  - 체크 1: 한글 음절과 한자 음(Reading)이 100% 일치하는가?
  - 체크 2: 부정적이거나 흉한 뜻의 한자가 섞이지 않았는가?
  - 체크 3: 기존 템플릿과 중복되지 않는 고유한 문학적 표현인가? (AdSense 고품질 기준)
  - 결과: 90점 미만 시 피드백과 함께 3단계로 반려(Self-Correction Loop) / 90점 이상 시 PASS!
       │
       ▼
[5단계: DB 영구 적재 (Upsert) & 동적 Sitemap.xml 자동 등록]
  - 다음 방문자부터는 정적 페이지 속도로 즉시 제공되며, 구글/네이버 검색 커버리지에 자동 편입!
```

## 3. 검색 커버리지 극대화 (Programmatic SEO) 전략

### 3-1. 3계층 시맨틱 URL 아키텍처 (크롤링 예산 & 내부 링크 최적화)
검색엔진 크롤러가 수만 개의 이름 페이지를 고립된 페이지(Orphan Page) 없이 3클릭 이내에 모두 수집할 수 있도록 **계층형 허브(Hub & Spoke)** 구조를 적용합니다.
1. **Tier 1 (메인 & 초성 허브)**: `/` 및 `/names/initial/ㄱ` ~ `/names/initial/ㅎ` (14개 초성 인덱스)
2. **Tier 2 (인기 음절/성별/분위기 허브)**: `/names/syllable/윤`, `/names/vibe/맑고_투명한` (연관 이름 내부 링크 20개씩 자동 연결)
3. **Tier 3 (개별 이름 랜딩 페이지)**: `/name/서윤`, `/name/지안`, `/name/도윤`, `/name/하준` (핵심 트래픽 유입점)

### 3-2. 롱테일 키워드 타겟팅 매트릭스
하나의 `/name/[이름]` 페이지가 아래 5가지 검색 의도(Search Intent)를 동시에 상위 노출하도록 `<h1>`, `<h2>`, FAQ 스키마를 설계합니다.
- **의도 A (이름 뜻 검색)**: `"[이름] 뜻"`, `"[이름] 이름 뜻풀이"`, `"한글 이름 [이름] 의미"`
- **의도 B (한자 조합 검색)**: `"[이름] 한자"`, `"[이름] 예쁜 한자"`, `"[이름] 한자 추천"`
- **의도 C (작명/개명 참고)**: `"[이름] 이름 느낌"`, `"[이름] 발음 오행"`, `"아기 이름 [이름]"`
- **의도 D (익명 편지/선물)**: `"[이름]에게 편지"`, `"[이름] 응원 메시지"`, `"[이름] 이름시"`

### 3-3. 기술적 SEO (Technical SEO) 체크리스트
- **Next.js App Router SSR + ISR (`revalidate = 3600`)**: 첫 생성 후 정적 HTML로 캐싱되어 TTFB(Time to First Byte) 100ms 이하 달성.
- **Selective Indexing (`isIndexable` 가드레일)**: 품질 검증 점수 90점 이상인 정상 이름 페이지만 `<meta name="robots" content="index, follow">` 및 `sitemap.xml`에 포함하여 사이트 전체 도메인 점수(Domain Authority) 보호.
- **Schema.org 복합 구조화 데이터 (`@graph`)**:
  - `DefinedTerm`: 구글 지식 그래프 및 AI Overview 인용 유도
  - `FAQPage`: 검색결과 화면(SERP)에서 아코디언 리치 스니펫 점유율 확대
  - `BreadcrumbList`: `홈 > ㅅ 초성 이름 > 서윤(瑞潤) 뜻풀이` 경로 표시

## 4. Google AdSense 연동 및 수익화 완벽 가이드

### 4-1. 애드센스 승인 및 정책 위반 방어 전략 (가장 중요!)
프로그래매틱 SEO 사이트가 Google AdSense를 붙일 때 겪는 2대 리스크와 해결책입니다.
1. **리스크 1: '가치가 낮은 콘텐츠(Low-Value / Thin Content)' 승인 거절**
   - **원인**: 한자 단어 몇 개만 나열된 짧은 페이지를 수천 개 생성하면 애드센스 봇이 자동 생성 스팸으로 간주합니다.
   - **해결**:
     - 승인 신청 전에는 **품질 검증 95점 이상을 받은 고품질 이름 300~500개**만 먼저 `index` 처리합니다.
     - 각 페이지마다 **① 대표 한자 시적 해설(700자+) ② 음절별 어원·획수·상징 카드 ③ 서브 한자 조합 2선 비교표 ④ 이름 분위기 키워드 & 어울리는 계절 ⑤ 맞춤 FAQ 3문항**을 포함하여 페이지당 순수 텍스트 분량을 최소 1,200자 이상으로 유지합니다.
2. **리스크 2: 익명 메시지(UGC) 악성 글로 인한 '퍼블리셔 정책 위반(경고/광고 제한)'**
   - **원인**: 구글 애드센스는 욕설, 괴롭힘, 성적 암시, 개인정보가 포함된 사용자 생성 콘텐츠(UGC) 페이지에 광고가 함께 노출되는 것을 엄격히 금지합니다.
   - **해결**:
     - 메시지 등록 시 `auditAnonymousMessageSafety()` 검증기가 욕설뿐 아니라 **문맥상 비아냥, 실명+소속 특정(사이버불링), 연락처 노출**을 실시간 차단합니다.
     - 설령 신고가 접수된 메시지가 있더라도 즉시 블라인드 처리하며, 익명 메시지 작성 폼 내부에는 광고를 넣지 않고 **검증된 메시지 피드 사이(In-Feed)**에만 광고를 배치합니다.

### 4-2. 화면별 Google AdSense 최적 슬롯 설계 및 수익(RPM) 극대화 배치

| 슬롯 번호 | 위치 (Placement) | AdSense 포맷 | 크기 / CLS 방어 규격 | 기대 효과 및 전략 |
| :--- | :--- | :--- | :--- | :--- |
| **Ad Slot #1** | 상단 검색바 아래 / 대표 한자 카드 위 | 디스플레이 반응형 (`auto`) | `min-h-[100px]` (모바일/PC 공통) | Above-the-fold(첫 화면) 노출률(Viewability) 95% 이상 확보 |
| **Ad Slot #2** | **한자 뜻풀이 스토리 본문 직하단** | **인아티클 (`fluid` / In-Article)** | `min-h-[160px]` (본문 폭 100%) | **[핵심 수익원]** 사용자가 자기 이름의 예쁜 뜻풀이를 읽고 감동한 직후 시선이 머무는 구간으로 **CTR(클릭률) 최고점** |
| **Ad Slot #3** | 익명 메시지 전달소 카드 3번째 뒤 | **인피드 (`fluid` / In-Feed)** | 카드 그리드 동일 높이 (`min-h-[180px]`) | 익명 편지 카드와 유사한 네이티브 카드 스타일로 이질감 없이 높은 전환 유도 |
| **Ad Slot #4** | 페이지 하단 연관 이름 추천 위 | 멀티플렉스 (`autorelaxed`) | `min-h-[250px]` | 이탈 직전 사용자에게 격자형 추천 콘텐츠/광고 노출 |

### 4-3. 기술적 연동 절차 (Step-by-Step)
1. **`public/ads.txt` 루트 배포**:
   ```text
   google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0
   ```
2. **Next.js `app/layout.tsx`에 AdSense 스크립트 비동기 로드 (`afterInteractive`)**:
   ```tsx
   import Script from "next/script";
   // <head> 내부에 삽입하여 초기 렌더링 블로킹(LCP 저하) 방지
   <Script
     async
     src={`https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=${process.env.NEXT_PUBLIC_ADSENSE_CLIENT_ID}`}
     crossOrigin="anonymous"
     strategy="afterInteractive"
   />
   ```
3. **고정 높이 스켈레톤 래퍼(`AdSenseBanner.tsx`) 사용**: 광고가 로드되기 전에도 `min-height` 박스를 유지하여 **CLS(Cumulative Layout Shift) 0.00**을 달성합니다(Core Web Vitals 통과로 구글 SEO 가산점 획득).

## 5. 화면별 UI 상세 명세 (5대 핵심 화면)
1. **화면 1 [홈 & 한글 이름 검색 허브]**:
   - '이름을 설명해드립니다' 히어로 영역 + 한글 이름 검색창(자동완성 & 초성 필터)
   - 실시간 DB 커버리지 카운터 (예: 사전 구축 5,240개 + Gemini 실시간 등재 1,892개)
   - 실시간 인기 이름 TOP 8 배지 & 방금 검증을 통과해 새로 등록된 이름 라이브 피드
2. **화면 2 [이름별 가장 예쁜 한자 뜻풀이 상세]**:
   - 대표 한자 캘리그라피 배너 + 시적인 한 줄 정의 + 품질 검증 완료 인증 배지(점수 표시)
   - 음절별 한자 분해 카드 (음·훈, 획수, 오행, 상징 키워드)
   - 심층 스토리텔링 해설 + 또 다른 예쁜 한자 조합 2선 비교 카드 + SEO FAQ 아코디언
   - AdSense Slot #1 (상단 배너) & AdSense Slot #2 (본문 직하단 인아티클 광고)
3. **화면 3 [Gemini 생성 × 품질 검증 라이브 파이프라인 뷰]**:
   - DB에 없는 새로운 한글 이름을 입력했을 때, ① 생성 에이전트 초안 작성 → ② 품질 검증 4대 항목 감사 및 감점/보완 지시 → ③ 최종 교정본 DB Upsert 및 Sitemap 등록 과정을 실시간 단계별 UI로 시각화
4. **화면 4 [익명 메시지 전달소 (우체통 & 바이럴 공유)]**:
   - 해당 이름(예: 전국의 '서윤'이들에게) 도착한 익명 편지 담벼락 + 수신자 힌트 태그(`#고등학교_동창`, `#우리팀_서윤님`)
   - 익명 편지 쓰기 드로어/모달 (우표 테마 4종 선택 + UGC 안전 클린봇 실시간 검증 표시)
   - 내 이름 전용 익명 우체통 링크 생성 & 공유 기능 + AdSense Slot #3 (인피드 광고)
5. **화면 5 [검색 커버리지(pSEO) & Google AdSense 수익 시뮬레이터 / 화면 설계도]**:
   - AdSense 슬롯 와이어프레임 ON/OFF 토글, 일일 검색 유입수·CTR·CPC 기반 월간 예상 애드센스 수익 계산기, JSON-LD 및 `sitemap.xml` 실시간 프리뷰
